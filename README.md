# HTML Arcade

Twenty-eight games. Each one is a single, self-contained HTML file: no installs, no internet, no dependencies.

| Game | What it is |
|---|---|
| `lumen-rush.html` | 3D raymarched neon tunnel racer (needs WebGL2) |
| `neon-swarm.html` | Twin-stick arena shooter with upgrades and bosses |
| `gem-alchemy.html` | Match-3 puzzler: 40 levels + Blitz mode |
| `sling-golf.html` | Physics mini golf: 36 holes across four courses |
| `sky-dash.html` | Synthwave rooftop runner with missions and skins |
| `chess.html` | Full-rules chess vs computer or 2 players, with clocks and a scoreboard |
| `drop-four.html` | Four-in-a-row vs computer or 2 players, with a scoreboard |
| `sonar-sweep.html` | Mine-finding logic puzzle with best-time tables |
| `prism-stack.html` | Falling-block puzzler: Marathon, Sprint and Ultra with high scores |
| `neon-puck.html` | Air hockey vs computer or 2 players on one screen, with a scoreboard |
| `brick-bloom.html` | Brick breaker with power-ups and endless levels |
| `solitaire.html` | Classic patience card game with stats and top scores |
| `boom-ridge.html` | Turn-based tank artillery, vs computer or 2 players |
| `trash-panda.html` | Silly maze-chase: a raccoon vs the night-shift janitors |
| `noodle-slurp.html` | A spaghetti noodle slurping meatballs on Nonna's table |
| `pigeon-panic.html` | One-tap flyer: a pigeon escaping with a stolen baguette |
| `reply-all.html` | Shoot coffee at waves of spam emails and the 9am Meeting |
| `why-chicken.html` | Endless road-crossing chicken with a new reason every 25 lanes |
| `angry-squaddy.html` | British Army horde survival with evolving weapons and 2-player co-op |
| `breachline.html` | Tap to crack firewalls before the trace finds you, then upgrade your rig |
| `syndicate.html` | 1v1 crime-empire bluffing duels across three territories |
| `lost-on-the-plain.html` | Open-world roguelike: find each RV across an endless map, with village shops and perks |
| `bleep-test.html` | Hold-to-sprint shuttle runs against the beep, with upgrades and a heckling PTI |
| `the-tab.html` | Endless loaded march with jumps, water, a kit store and a day/night cycle |
| `pressup-empire.html` | Idle clicker: press-ups, recruits, upgrades and Pass Out prestige |
| `rank-up.html` | Merge puzzle up the ranks from Recruit to Field Marshal, with powers |
| `camo-cross.html` | Picture logic puzzles (nonograms): 22 pictures plus an endless mode |
| `draughts.html` | English draughts vs the computer (3 levels) or 2 players |

**Play:** download `html-arcade.zip` from the [Releases](../../releases/latest) page, unzip it, and open `index.html` (or any game file) in a browser. Works offline from a USB stick.
